Welcome to Technology Center

Technology Center is a simple Flask based web application designed to manage trainer information and course details. This system allows users to add trainer records, store information inside a MySQL database and display the saved data on a separate page. It also demonstrates how Flask routes, templates, static files and database connectivity work together to build a small web application.
